A block-based page editor for Blazor

Let your users build structured pages by arranging blocks in a visual editor. You decide which blocks exist and how content is stored and rendered.

Get started View on GitHub

Pre-release: BlazorBlocks is a working prototype and is not on NuGet yet.

Features

Drag & drop

Rearrange groups and blocks, including moving blocks between columns.

Flexible layouts

Six built-in group layouts: 1, 2, 3 and 4 columns, plus 1+2 and 1+2+full.

Built-in blocks

Title, Raw Text, Image, and Quote, ready to use.

Live preview

See the rendered HTML of the page while you edit.

JSON round trip

Export the whole page to JSON and load it back whenever you need.

Extensible

Register your own block types with a model and an editor component.

Themeable

Style it with --bb-* CSS custom properties and bb- prefixed classes.

How it works

Content is organised in three levels.

  1. Groups are the layout containers on a page.
  2. Columns live inside a group.
  3. Blocks live inside columns and hold the actual content.

Your app persists the result as JSON and renders it as HTML.

Get started

BlazorBlocks targets .NET 10. Until a release is on NuGet, clone the repository and reference the project.

git clone https://github.com/ThindalTV/BlazorBlocks.git

Register the services in Program.cs:

builder.Services.AddBlazorBlocks();

Then add the editor to a page:

<BlazorBlocksEditor Model="_model" OnModelUpdated="OnModelUpdated" />

Custom blocks

Register your own model and editor component:

builder.Services.AddBlazorBlocks()
    .AddBlazorBlockEditor<SampleBlockModel, SampleBlockEditor>("Sample");
